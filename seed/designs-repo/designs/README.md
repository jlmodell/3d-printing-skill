# Designs

One folder per project:

```text
designs/<project>/README.md
designs/<project>/vN/README.md
designs/<project>/vN/NOTES.md
designs/<project>/vN/images/
designs/<project>/vN/<mesh files>
```

Templates are in `../templates/`. Create a version folder when there is a mesh,
a `NOTES.md`, and a preview image to put in it. Print history that predates
those files is in `../print-log.md`.
